# Shelf — Personal Book Library

A React, TypeScript, and Redux Toolkit reading list for keeping track of the books you want to read and the ones you have finished.

## Run locally

```sh
npm install
npm run dev
```

Use `npm run build` to type-check and create a production build.

## Features

- Add books with a title, author, genre, and optional note.
- Mark books as read, remove them, and see reading totals.
- Search by title, author, genre, or note; filter by reading status and genre.
- Sort by recently added, title, or author.
- Save the collection in browser local storage.
